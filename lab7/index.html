Lab 7: Temporal Data Visualization

This page presents temporal visualizations of weather data and an animated commercial network over 60 days.

Part A: Historical Weather Line Chart

Part B: Animated Commercial Network (60 Days)

Day 1

Legend

Design Description

Weather line chart: Time is mapped to the x-axis using a time scale, and the selected weather metric is mapped to the y-axis. Multiple cities are distinguished by color. A dropdown lets the user switch metrics, and hovering over the chart shows the closest observation's details.

Animated network: Companies are nodes, and transactions are links. At each time step, only transactions for the current day are shown. New links fade in, disappearing links fade out, and node sizes reflect the current transaction volume. The force simulation is gently restarted each frame to preserve the mental map.

Temporal Network Questions

Question Observation
1. How does overall network connectivity change across the 60 days? Use the day slider to observe fluctuations. The network typically shows more links in the middle of the period.
2. Which companies become more central or commercially active over time? Node size reflects transaction volume. Larger nodes indicate more active companies.
3. Are there periods when the network consists of relatively separate clusters? Some days show disconnected groups; others show a more integrated network.
4. Which commercial relationships appear, disappear, or become stronger? Links fade in and out. Hover a link to see details.
5. Does the network become more or less cross-regional over time? By looking at node colors and link endpoints, you can observe whether cross-region transactions increase.
