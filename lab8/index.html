Lab 8: Web Text Data and Visualization

This page presents an interactive exploration system for the DKU Undergraduate Bulletin. It coordinates a semantic embedding map with a Topic × Section matrix.

Corpus Description

Document: DKU Undergraduate Bulletin (V2021-22)
Source: Duke Kunshan University
Unit of analysis: One paragraph / policy block = one passage
Embedding model: all-MiniLM-L6-v2
Dimensionality reduction: UMAP (n_neighbors=15, min_dist=0.15, metric=cosine)
Clustering: KMeans (k=8)

1. Semantic Embedding Map

Click a point to see passage details.

2. Topic × Bulletin Section Matrix

Design Description

Embeddings: Each passage is encoded with a sentence transformer (all-MiniLM-L6-v2), producing a high-dimensional semantic vector. UMAP projects these vectors to 2D so that nearby points tend to be semantically similar.

Topics: KMeans clustering groups passages by embedding similarity. Each cluster is labeled using its top TF-IDF terms and representative passages.

Visual encodings:
• Semantic map: x/y = UMAP coordinates; color = semantic topic; size = passage length.
• Matrix: rows = bulletin sections; columns = semantic topics; cell color = passage count.

Coordinated interaction: Clicking a matrix cell highlights the corresponding passages in the semantic map. Conversely, selecting a point in the map highlights its cell in the matrix.

Findings

  1. Major semantic topics: Clusters correspond to registration, degree requirements, academic integrity, graduation, study away, and student support.
  2. Topics across sections: "Credit" and "requirements" appear in both Degree Requirements and Transfer Credits sections.
  3. Most diverse sections: Academic Policies contains passages from many different clusters.
  4. Similar passages across sections: Passages about graduation requirements in Degree Requirements and Graduation sections cluster together.
