Lab 2: Multivariate Visualization with D3

This visualization explores the relationship among population, temperature, development level, and region.

Design Justification

Mapping choices:
• Population → x-position (ratio variable)
• Temperature → y-position (interval variable)
• Development Level → size (ordinal: Low < Medium < High)
• Region → color (nominal: North, South, East, West)

Reasoning:
I chose this mapping because the x and y axes naturally represent continuous numerical data, making it easy to see relationships between population and temperature. Using size for development level visually emphasizes the ordinal hierarchy, while color clearly distinguishes the four regions. This design allows viewers to quickly identify patterns and outliers.
