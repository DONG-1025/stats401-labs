5. Design Description

Visual channels:
• GDP amount → rectangle area in treemaps, and node depth position in the tree.
• GDP status → color.
• Hierarchy → spatial nesting in treemaps; branch structure in the tree.

Why these channels: Rectangle area is a natural encoding for a quantitative value like GDP because area comparisons are intuitive. Color is well-suited to a small categorical variable, allowing viewers to spot patterns like clusters of decreasing GDP within a region.

Comparing the two treemap methods: The squarify layout produces rectangles with aspect ratios closer to squares, making labels easier to read and overall structure cleaner. The binary layout recursively splits space into two groups, which often produces longer, thinner rectangles but can reveal grouping patterns more strongly. Both use the same data and coloring, so the difference is purely spatial.
