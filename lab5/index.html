Lab 5: Interactive Network Visualization

This page presents an urban transit network of 50 stations and 50 direct connections. The network is visualized in two ways: as an interactive force-directed node-link diagram and as an adjacency matrix.

Dataset Description

Dataset: Synthetic Urban Transit Network
Stations: 50
Direct connections: 50
Node variables: district, daily_passengers, station_type
Link variables: travel_time_min, route_type
Districts: Central, North, South, East, West

1. Node-Link Visualization

2. Node-Link Design Description

Node encodings:
• district → node color
• daily_passengers → node size
• station_type → node border style

Link encodings:
• travel_time_min → link width
• route_type → link color and dash pattern

Interactions:
• Dragging — allows the user to reposition nodes and explore alternative layouts.
• Hover highlighting — hovering over a node highlights it and its direct neighbors, dimming all other nodes and links.
• Tooltips — hovering over a node displays its full details: name, district, daily passengers, and station type.

3. Adjacency Matrix

4. Matrix Design Description

Matrix encodings:
• row / column → station
• filled cell → direct connection between two stations
• cell color → route type
• cell opacity → travel time
• label color → district

Ordering: Stations are sorted by district so that within-district connections form visible blocks along the diagonal. This makes it easier to see whether stations tend to connect within their own district or across districts.

5. Network Questions and Findings

Question Best View Encoding / Interaction Answer / Observation
1. Which stations appear central in the network? Node-link Node position + hover highlighting Stations in the Central district tend to appear near the middle of the force layout and have many visible connections, suggesting they are the most central.
2. Which districts are strongly connected to one another? Adjacency matrix Block patterns + cell color The matrix shows dense blocks along the diagonal for each district, but also off-diagonal cells linking adjacent districts.
3. Where are transfer or terminal stations located in the topology? Node-link Node border style Transfer stations tend to be positioned between districts, acting as bridges. Terminal stations appear at the periphery.
4. Which stations have high passenger volume? Node-link Node size The largest nodes are concentrated in the Central district and at transfer points, indicating high daily passenger volume.
5. Where are the longest direct travel-time connections? Both Link width + cell opacity The thickest links in the node-link view and the darkest cells in the matrix correspond to longer travel times, mostly between peripheral districts.
6. Are particular route types concentrated in particular parts of the network? Adjacency matrix Cell color Metro routes dominate the Central district, while Shuttle routes are more common in the outer districts. Express routes appear between districts.
